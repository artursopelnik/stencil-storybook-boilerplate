`ssb-radio` renders a single radio option with a styled circle and a slotted label. It is designed to be used inside `ssb-radio-group`, which coordinates the selection.

## Table of Contents

- [Intent](#intent)
- [Guidelines](#guidelines)
- [Examples](#examples)
- [Properties](#properties)

---

## Intent

Use a radio to present one option of a mutually exclusive set inside an `ssb-radio-group`. Do NOT use a standalone radio as an on/off control — use a checkbox or a switch for independent boolean settings.

---

## Guidelines

- **Do** always give each radio a unique `value` within its group.
- **Do** provide a visible label via the default slot; the whole label is clickable.
- **Do** let `ssb-radio-group` manage the `checked` state instead of toggling it manually.
- **Don't** place radios of the same set outside a shared `ssb-radio-group`.
- **Don't** use a radio to trigger an immediate action — use `ssb-button` for actions.
