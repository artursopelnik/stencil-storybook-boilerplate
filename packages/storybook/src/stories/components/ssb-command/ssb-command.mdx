`ssb-command` is a command palette: a search input over a grouped, keyboard-navigable list of commands.

## Table of Contents

- [Intent](#intent)
- [Guidelines](#guidelines)
- [Examples](#examples)
- [Properties](#properties)

---

## Intent

Use a command palette to let power users find and run actions quickly by typing. Do NOT use it for plain navigation menus — use `ssb-dropdown-menu` there.

---

## Guidelines

- **Do** place it inside `ssb-dialog` to build a modal ⌘K-style palette.
- **Do** group related commands and show shortcuts where they exist.
- **Don't** overload the palette with rarely useful actions; keep the list curated.
- **Don't** use it as a general search field for content — it selects commands, nothing else.
