`ssb-native-select` is a styled native `<select>` following the Basecoat UI select look. Options are passed as an array (or JSON string attribute) and the component emits `ssbChange` on selection.

---

## Intent

Use a native select to let people pick exactly one option from a medium-sized list while keeping the platform's native dropdown behavior. Do NOT use a select for two or three options that could be shown at once — use `ssb-checkbox` groups or radio-style controls instead.

---

## Guidelines

- **Do** provide a `placeholder` so the control does not silently preselect the first option.
- **Do** keep option labels short and sort them in a predictable order.
- **Do** pass `options` as a JSON string when using the component from plain HTML attributes.
- **Don't** rely on native form submission — the select lives inside shadow DOM; read the selection via the `ssbChange` event or the `value` prop.
- **Don't** use a native select for very long lists that need search or filtering.
