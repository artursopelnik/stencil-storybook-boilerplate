`ssb-textarea` is a multiline text input styled after the Basecoat UI textarea. It wraps a native `<textarea>` and emits `ssbInput` and `ssbChange` events.

## Table of Contents

- [Intent](#intent)
- [Guidelines](#guidelines)
- [Examples](#examples)
- [Properties](#properties)

---

## Intent

Use a textarea to collect longer, multiline free-form text such as messages, comments, or descriptions. Do NOT use a textarea for short single-line values — use `ssb-input` instead.

---

## Guidelines

- **Do** pair the textarea with `ssb-label` or `ssb-field` so people know what to enter.
- **Do** set `rows` to roughly match the expected length of the content.
- **Do** set `invalid` together with an error message when validation fails.
- **Don't** rely on native form submission — the textarea lives inside shadow DOM; read values via the `ssbInput`/`ssbChange` events or the `value` prop.
- **Don't** disable vertical resizing needs by cramping content into a tiny textarea.
