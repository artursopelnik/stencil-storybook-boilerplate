`ssb-button` triggers an action or navigates when a `href` is provided. Variants and sizes follow the Basecoat UI button.

---

## Intent

Use a button to let people trigger an action such as submitting data, opening a dialog, or navigating (with `href`). Do NOT use a button for purely decorative labels — use `ssb-badge` for status labels and plain links for inline text navigation.

---

## Guidelines

- **Do** use exactly one `primary` button per view to mark the main action.
- **Do** use the `destructive` variant for irreversible actions such as deleting data.
- **Do** provide an `aria-label` via the `aria` prop for `icon` size buttons.
- **Don't** use a button where a plain inline link inside running text is expected.
- **Don't** rely on implicit form submission — buttons inside shadow DOM do not submit surrounding forms.
