`ssb-button-group` visually joins slotted `ssb-button` elements into one segmented control: inner corners are squared and adjacent borders collapse.

## Intent

Use a button group to present a small set of closely related actions or mutually related commands as one visual unit, such as pagination or text alignment. Do NOT use a button group for unrelated actions — keep independent actions as separate buttons.

---

## Guidelines

- **Do** slot only `ssb-button` elements into the group.
- **Do** use the same `variant` (preferably `outline` or `secondary`) for every button in the group.
- **Do** provide a group label via the `aria` prop (`aria-label`).
- **Don't** mix `primary` and `destructive` buttons inside one group.
- **Don't** use a button group when only a single action exists.
