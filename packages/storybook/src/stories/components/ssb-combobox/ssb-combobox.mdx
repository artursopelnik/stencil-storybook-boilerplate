`ssb-combobox` is a searchable select: a trigger opens a panel with a filter input and a filtered listbox.

---

## Intent

Use a combobox when people pick one option from a long list where searching is faster than scrolling. Do NOT use it for short lists — `ssb-select` or `ssb-radio-group` are simpler there.

---

## Guidelines

- **Do** keep option labels short and distinctive so substring search works well.
- **Do** customize `emptyMessage` to tell people what to do when nothing matches.
- **Don't** rely on native form submission — read the value via the `ssbChange` event or the `value` prop.
- **Don't** use it for free-text input; it only selects from the given options.
