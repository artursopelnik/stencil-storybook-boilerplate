`ssb-alert` displays a callout box with an optional icon, a title and a description. Variants follow the Basecoat UI alert.

- [Guidelines](#guidelines)

---

## Intent

Use an alert to draw attention to important contextual information such as warnings, errors, or status messages that relate to the current view. Do NOT use an alert for transient feedback after user actions — use a toast-style notification instead.

---

## Guidelines

- **Do** keep the title short and put details in the description text.
- **Do** use the `destructive` variant for errors and irreversible failures.
- **Do** provide an icon in the `icon` slot to reinforce the message type.
- **Don't** stack many alerts on one view — consolidate related messages.
- **Don't** use alerts for marketing or promotional content.
