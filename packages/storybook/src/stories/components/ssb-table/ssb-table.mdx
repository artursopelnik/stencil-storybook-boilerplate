`ssb-table` renders tabular data from `columns` and `rows` props as a semantic table with muted headers, row hover, and optional striping and compact density.

## Intent

Use a table to present structured records that people compare across rows and columns, such as invoices or users. Do NOT use a table for page layout or for content that is not truly tabular — use cards or lists instead.

---

## Guidelines

- **Do** right-align numeric columns via `align: "right"` so digits line up.
- **Do** add a `caption` describing the table for assistive technology.
- **Do** use `compact` for dense, data-heavy screens.
- **Don't** mix unrelated data sets in a single table.
- **Don't** rely on striping alone to convey meaning — it is purely visual.
