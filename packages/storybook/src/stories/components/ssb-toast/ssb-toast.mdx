`ssb-toast` shows a brief notification with an optional auto-dismiss timer and emits `ssbClose` when it is closed. The component renders in place — consumers are responsible for positioning it, typically inside a fixed container in a page corner.

## Intent

Use a toast for brief, non-blocking feedback about an operation, such as "Saved" or "Copied to clipboard". Do NOT use a toast for messages that require a decision or must not be missed — use `ssb-dialog`, `ssb-alert-dialog` or an inline `ssb-alert` for those.

---

## Guidelines

- **Do** position the toast yourself, e.g. inside a `position: fixed` container in a page corner.
- **Do** set a `duration` of a few seconds for transient confirmations.
- **Do** use the `destructive` variant for errors so the toast is announced assertively via `role="alert"`.
- **Don't** disable `dismissible` while also leaving `duration` at `0` — the toast would never close.
- **Don't** stack many toasts at once or use them for essential information.
